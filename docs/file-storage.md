# File Storage

> **Status:** Documentation only. Local storage during MVP. Cloud migration is future work.

## MVP Approach

Files are stored **locally** on the Django server filesystem during MVP development. The directory structure should allow migration to cloud storage (e.g., S3) later without changing business logic significantly.

## Upload Rules

Applies to **reference materials** and **task submission** file uploads:

| Rule | Value |
|------|-------|
| Maximum size | **20 MB per file** |
| Allowed types | PDF, DOC, DOCX, PPT, PPTX, PNG, JPG, JPEG, TXT, CSV, ZIP |

External links are stored as URLs and are not subject to file upload rules.

Upload validation is **not implemented yet**; rules are documented for the implementation phase.

## File Categories

### Reference Materials

Belong to an **Internship Program**. One program may have **multiple** reference materials.

**Supported content (MVP):**
- File uploads (allowed types above)
- External links (stored as URLs)

**Purpose:** Provide AI with company materials, standards, resources, or training documentation during roadmap generation.

**Note:** File parsing for AI context is not implemented in scaffolding phase.

### Task Submissions

Uploaded by interns as part of task submissions.

- Each submission may include **multiple** uploaded files (allowed types above, 20 MB each)
- Each submission may include one optional **external link**
- Each new submission version may contain its own uploaded files
- Stored locally with path reference on Submission (or SubmissionFile records)

### Generated PDFs

Final internship summaries exported as PDF after Mentor approval.

- Generated using **ReportLab** (planned library, not implemented yet)
- Stored locally after generation
- Downloadable by Mentor and Intern (where allowed)
- Not uploaded by users; generated by the system

## Local Storage Layout (Suggested)

```
media/
├── reference-materials/
│   └── {program_id}/
│       └── {material_id}/
├── submissions/
│   └── {assignment_id}/
│       └── {submission_id}/
└── final-summaries/
    └── {summary_id}/
```

Exact paths are an implementation detail. Structure above is a placeholder convention.

## Cloud Migration (Future)

- Abstract file storage behind a service interface
- Swap local filesystem for cloud provider when requested
- Not part of MVP implementation

## Constraints

- Do not implement cloud storage now
- Do not implement file parsing for reference materials now
- Do not implement upload validation yet
