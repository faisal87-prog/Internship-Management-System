# Frontend — AI Internship Management Platform

Next.js (App Router) + TypeScript + Tailwind CSS frontend for the approved MVP.

**Status:** UI implemented with **mock data only**. No Django, PostgreSQL, JWT, or OpenAI integration.

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) and choose a demo user on the login screen.

## Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start development server |
| `npm run build` | Production build |
| `npm run start` | Start production server |
| `npm run lint` | Run ESLint |

## Styling

- Tailwind CSS with CSS variables for the orange company theme
- No additional UI frameworks

## Charts

- Polished CSS/Tailwind chart placeholders only
